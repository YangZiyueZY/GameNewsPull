# skill/ · 供 AI 智能体执行的仓库运维 Skill

本目录存放「定期手动维护」类 skill，面向**仓库运维人员及其 AI 助手**。
它们不参与站点构建，也不会被 GitHub Action 调用——是给人和 agent 看的作业指导书。

| 文件 | 用途 | 建议频率 |
|---|---|---|
| `SKILL.md` | 手写信源定期校正与验证（卡池时段、角色字典、活动种子、游戏配置、测试快照） | 每月 1 次 / 大版本后 / CI 连续告警时 |

## 怎么用

1. 人工：直接照 `SKILL.md` 的步骤执行。
2. AI agent：把 `skill/SKILL.md` 作为任务说明加载，按「执行前检查 → 体检 → 校正 → 提交验证」顺序执行；
   每一步都以 `npm test` 与 `data/health.json` 为验收依据，不要跳步。

## 与自动化的边界

- 每日 09:30 的 Action 负责**抓取与产出**（信源适配器 + 卡池引擎 + 构建 + 提交）。
- 本 skill 负责**校正与治理**：自动扩写补不上的角色名、官方不公布的结束时间、新游接入、信源改版后的适配。
